# Impress
---

*A super tiny program That I made in my free time.*
- can resize jpeg, png, and jpg files
- can change the quality of the image
- uses the terminal instead of UI
- uses the system file explorer to import and export finished photos
- is awesome and sweet

---

**This program was made in part with the use of generative AI and a heavy reliance on premade packages.**
#####  I love to make little tools like these to cope and adapt with our modern day reliance on bloat
(There is no reason a picture should be over 5 Mb if it isn't artwork, it's wasted space.)
